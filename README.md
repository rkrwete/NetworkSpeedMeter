Консольный скрипт на Python для замера скорости скачивания.
Он последовательно выполняет 10 GET-запросов к указанному URL, полностью скачивает каждый ответ и рассчитывает среднюю скорость.

## Установка
```bash
python -m venv .venv
source .venv/bin/activate  # Linux/macOS
.venv\Scripts\activate   # Windows PowerShell
pip install -r requirements.txt
```

## Запуск
```bash
python speedtest.py "url"
```

## Единицы измерения
```text
- Скорость: Mbit/s (мегабиты в секунду)
- Объём: MiB (мебибайты, 1 MiB = 1 048 576 байт)
- Время: секунды
```

## Как считается скорость
```text
скорость (Mbit/s) = (общий объём в мебибайтах × 8) / (среднее время в секундах)
```

## Пример вывода
```text
URL: https://samplelib.com/jpeg/sample-10mb.jpg
Успешных запросов: 10 из 10
Общий объём: 95.01 MiB
Общее время: 29.74 сек
Среднее время запроса: 2.97 сек
Средняя скорость: 3.19 Mbit/s
```
